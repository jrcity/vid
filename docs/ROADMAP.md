# VID — Project Roadmap 🚀

This roadmap outlines the journey of the Virtual ID (VID) system from its current prototype state to a continental identity infrastructure powered by Nokia Network-as-Code.

---

## 📍 Phase 1: Prototype & Proof of Concept (Current)
*Focus: Foundation and Core Logic*

- [x] **Core Backend**: FastAPI implementation with modular service architecture.
- [x] **Trust Engine**: Initial scoring logic for SIM Swap, Number Verify, and KYC Match.
- [x] **Mock Mode**: Simulation layer for Nokia NaC APIs to allow rapid frontend development.
- [x] **Pan-African Mockup**: Interactive HTML certificate demonstrating cross-border capability.
- [x] **Multi-SIM Logic**: Algorithm for cross-network identity corroboration.

---

## 🏗 Phase 2: Alpha — Live Integration
*Focus: Real-world connectivity and Sandbox testing*

- [ ] **Nokia NaC Live Link**: Transition from mock responses to live sandbox API calls.
- [ ] **Primary Country Pilots**: stabilize integration for the "Big Five" (Nigeria, Kenya, Ghana, South Africa, Ethiopia).
- [ ] **Consent Flow UX**: Refine the user opt-in process to ensure GDPR/NDPR compliance.
- [ ] **QR Verification API**: Build a dedicated endpoint for third-party scanning and verification.
- [ ] **Performance Tuning**: Optimize parallel API orchestration for sub-2-second latency.

---

## 🌍 Phase 3: Beta — Regional Expansion
*Focus: Scale and Ecosystem*

- [ ] **AU-20 Expansion**: Onboard 20+ African Union member states with localized VID labels (e.g., Fayda for Ethiopia, NIN for Nigeria).
- [ ] **Multi-SIM V2**: Enhanced corroboration logic for users with 3+ SIM cards across different operators.
- [ ] **Bank/NGO Pilot**: Partner with a financial institution or NGO for a "Real Identity" trial.
- [ ] **Offline Mode**: Basic QR verification that works in low-connectivity areas (signed hashes).
- [ ] **Developer SDK**: Beta release of the VID-Verify SDK for easy integration into existing apps.

---

## 🏛 Phase 4: Continental Launch — The Sovereign Layer
*Focus: Compliance and Sovereignty*

- [ ] **Full AU-54 Coverage**: Coverage across all 54 African nations.
- [ ] **Data Sovereignty Nodes**: Regional data handling to comply with local data residency laws.
- [ ] **Verifiable Credentials (VC)**: Transition to W3C Verifiable Credentials standard for interoperability.
- [ ] **Biometric Bridge**: (Optional) Integration with national biometric databases where APIs are available.
- [ ] **VID Governance**: Establishing a decentralized oversight council for identity standards.

---

## 📈 Long-term Vision
- **Cross-Border Remittances**: Instant KYC for faster, cheaper money transfers.
- **Continental Passports**: Digital companion to physical travel documents.
- **Universal Basic Services**: Streamlined access to government and aid services via phone-based identity.

---
> *Building the digital infrastructure for an integrated Africa.*
