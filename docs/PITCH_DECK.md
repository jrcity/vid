## Slide 4: How It Works (The Tech)
**Headline**: The Trust Engine.
**Visual**: A diagram showing 5 CAMARA APIs flowing into a Random Forest Model.
**Explanation**:
1. **Fetch**: Call SIM Swap, KYC Match, Location, etc.
2. **Score**: ML calculates a Trust Grade (0-100).
3. **Mint**: Generate a hashed VID Certificate + QR.
